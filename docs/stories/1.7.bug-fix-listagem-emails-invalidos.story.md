# Story 1.7: Exibição de e-mails inválidos após validação XLSX

## Status

**Status**: Ready for Review
**Executor**: @dev

## Story

**Como** usuário do BulkMail Pro,
**quero** visualizar os e-mails rejeitados após carregar uma planilha,
**para** identificar e corrigir os dados inválidos antes do envio.

## Acceptance Criteria

1. Após o upload, os e-mails inválidos devem ser exibidos na página inicial.
2. Cada item deve mostrar o endereço e o motivo da rejeição retornado pela API.
3. A lista deve aparecer mesmo quando todos os e-mails da planilha forem inválidos.
4. O resultado de um novo upload deve substituir a lista anterior.

## Tasks / Subtasks

- [x] Armazenar os itens inválidos retornados pela API.
- [x] Renderizar a seção de e-mails inválidos na página inicial.
- [x] Adicionar testes E2E para planilhas com e sem e-mails válidos.
- [x] Executar validações de qualidade e atualizar os containers.
